# Birthday Calculator

A Python command-line application that calculates a person's age, displays their birthday details, and determines how many days remain until their next birthday.

## Features
- Enter a person's name and birthday.
- Validate date input using exception handling.
- Display the birthday with the weekday, month, and year.
- Calculate the person's current age.
- Calculate the number of days until the next birthday.
- Display special messages when the birthday is today, tomorrow, or yesterday.
- Option to calculate another birthday.

## Python Concepts Used
- Functions
- `datetime` and `date` modules
- While loops
- If-elif-else statements
- Exception handling (`try` and `except`)
- String formatting (f-strings)
- Date calculations

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python birthday_calculator.py
```
